# 1.1.0 — delegated plugin sound design

`sound-design` now prepares actual-context tasks, makes isolated candidate
branches, saves/cold-reopens full native states, renders solo/context/repeat
auditions, produces matched previews, and applies/undoes sounds by channel IID.
Interrupted editing/rendering can resume from retained checkpoints.

Sytrus is the primary deep adapter: guarded Default-family FM/RM/OUT, ratios,
SH, 32 harmonics and explicitly enabled four-point volume envelopes. Generic
host controls remain separate and were exercised with Surge XT, including
discrete values that change only after reload. Unsupported layouts stay explicit.

A progressive specialist Skill, six source-attributed design recipes and 14
original sources accompany real bass/lead/pad and independent revision cases.
The local DSH preset adds a fixed specialist delegation route. See
[workflow](sound-design/README.md), [support](sound-design/support-matrix.md)
and [validation](sound-design/validation.md).

Install `.[sound-design]` for NumPy analysis; MIDI support remains optional.
Signal analysis does not establish taste or contextual preference. Hidden
plugin assets, unadapted state and current desktop reload remain disclosed in
the validation record.
