# 听感目标：先选解释，再执行配方

以下都从 [Sytrus 的受控起点](sytrus.md)出发。数值是候选起点，尚未经本机听验。资料中的知觉关联不等于这些中文词的固定翻译。保留参考声音、用途、音域、演奏与编曲；没有参考时，可以产生两个清楚标记解释的候选，不能默认“所有旋钮一起增加”。

| 用户词 | 至少两种合理解释 | 首轮选择的机制与可操作动作 | 预期、验证、失败替代 |
|---|---|---|---|
| 温暖 | 高频较少/圆润；轻度饱和的谐波；也可能只是低中频多 | OP1 saw→F1低通，关闭OP1直出；以当前cutoff为基线降低1个八度，resonance保持低，先不加失真 | 预期较少高次成分；匹配响度后确认“柔和”是否保留清晰度。变闷时先恢复半个八度或改为triangle，不默认增强低频。暖不等于低频越多越好（P01/P02/C02；审美映射为假设） |
| 亮 | 富高次谐波；尖锐起音；高音域；响度更大 | 分开试两条：同一saw提高低通cutoff一个八度；或sine起点加FM OP2→OP1=10%，OP2 ratio2，OP2不直出 | 预期谱/起音改变；补偿增益后由人判断是否更亮、更刺。若刺耳，减FM或减filter envelope深度；不要为了提高centroid升高演奏音域（P01/P02/C04） |
| 空灵 | 长起音/尾音的悬浮；明亮而稀疏；airy/breathy气息；远处空间 | 先做无FX的sine/triangle候选：AEG A300ms、R900ms；保持单一carrier。再单独比较轻度stereo/FX，记录干湿路由 | 预期边界较柔和、音间有重叠；短音符/长和弦都要验证。若“糊”或吞起音，缩短R/A；若用户要气息而非漂浮，换少量NS噪声候选。R01明确airy/breathy不能由一般noisiness代替（P01/C03/R01） |
| 厚 | 同时声部多/失谐拍频；低音层；和弦配器；更大声 | 首轮只把Unison order从1改3，PT从0向小量增加，先收窄pan；音量补偿后再试pan | 预期拍频/谱与声像改变；单音、和弦、单声道分别检查。若音高漂、低频相消或混音拥挤，回到1声部，改少量OP2同音轻失谐或调整八度/配器；不是无条件堆9声部（P01/P03/C01） |
| 近 | 干、清楚的起音/较高直达声比例；也可能是更响或中频突出 | 保持干音、FXsend0；AEG A5ms、R120ms，保留原音高与演奏力度；再在编曲中调整音量 | 预期瞬态与音符间隙更清楚；与响度匹配后的较长A/R候选比较，再放入上下文。若变“硬”而非“近”，恢复部分A/R或少量空间；不能用centroid/峰值推断距离（R02/R03/C03；距离映射是经验假设） |
| 颗粒 | 慢拍频/粗糙度；高频噪声；短脉冲颗粒；数字失真；演奏纹理 | 先提供两个互斥候选：A小量NS噪声，B独立RM OP2→OP1由0→10%，不叠FM；维持相同音域、力度、响度 | 预期A增加非周期成分，B增加调幅/边带。由人选择“气/砂/粗/碎”中哪一种更近；不以flatness判达标。若只变刺，减噪/调制；若用户指颗粒合成，明确Sytrus这一配方没有granular采样引擎，转为节奏切片/包络方案（R01/C04/C05/P01） |

## 包络：声音的时间形状与音色的时间形状分开

修改 OP1 VOL→ENV 主要改变 carrier 的幅度时间曲线；修改 OP2 VOL→ENV，且只有 OP2→OP1 的 FM 连线时，主要改变 FM 深度的时间曲线；修改 FILT1 CUT→ENV 则改变经过滤波路线的 cutoff 时间曲线。三者不能互相冒充。

- 想要拨感而保持延音：先试短促的 OP2 调制包络或 CUT 包络，保留 OP1 的持续段。
- 想要真正短音：缩短 carrier 的幅度包络，并实际发送 note-off；尾音窗口不能截短到把R误判为0。
- 想要连奏：检查 note gate、mono/legato/retrigger 与多声部重叠。相同ADSR在不同触发规则下会不同（C03）。

## 立体声与上下文

3xOsc 官方手册将 Phase OFS、Detune、Panning 分为不同参数，并指出立体声相位起点可能引入点击；Unison 与 chorus 也不是同一种处理。测试宽度时保留单声道版本，按 `M=(L+R)/2` 检查左右抵消，并听低音和核心旋律是否变弱。单声道损失多少可接受是设计决定，不能从“相关系数变低”自动推出“更空灵/更厚”。

R03 的融合与前景/背景分析表明，同一声音放入不同伴奏，可能改变它是否突出、融合或被听成背景纹理。每个候选至少保留干音单独版本与固定伴奏版本。若在伴奏里失去清晰度，先处理音域、音符密度、重叠release和配器，再考虑继续增加亮度或声部。
