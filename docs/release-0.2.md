# 0.2 实际验证

2026-10-26，Windows x64，FL Studio Producer26.1.6.5639。

开发已转向保存工程的文件后端；没有采用旧MCP的自动Piano Roll脚本。
原80项参数化细测已收敛为3个工作流回归；native导出与独立盲测使用真实FL。

已完成的真实FL检查：

- 创建五个独立通道，各有不同的音符和采样；FL原生导出确认各自时间区段均发声。
- 130 BPM的四小节、71音符编曲（12/8/37/6/8），FL导出7.389秒的44100Hz立体声WAV。
- 从本机预设创建3x Osc音源，再加入Fruity Reeverb 2；原生渲染中音频内容与尾音长度改变。
- 通道经Insert1→Insert6→Master编组，原生渲染与直通声轨一致。
- 渲染在私有Windows桌面运行，不要求关闭用户编辑器；没有注入快捷键或修改原工程。

文件级结果都明确是新副本；实际FL进程每次重新打开该副本再渲染。
本轮没有声称实现任意live工程接管、全部Automation或未知第三方插件控件。
